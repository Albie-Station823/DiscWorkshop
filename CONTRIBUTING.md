# Contributing

Open an issue describing a bug or proposed change before a substantial contribution. Include app version, Windows version, reproduction steps, expected behavior, and a short relevant error excerpt. Remove personal paths and sensitive information from logs.

Build with the command in README.md. Keep patches focused and include relevant checks. Prefer synthetic fixtures. Do not upload movies, proprietary codecs, installers, credentials, or third-party binaries. Contributions are offered under this repository's GPLv2 license.
